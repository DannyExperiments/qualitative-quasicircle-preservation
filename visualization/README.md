# Explore two arcs and one short chord

Open index.html in a browser. The explorer works offline without dependencies. The stretch control applies \(A_L(x,y)=(Lx,y)\) to the marked polygon. Drag Rotation or use Rotate to see the parallel source and image planes. The planes share the same scale. The white dotted segment joins the two endpoints, mint marks the arc through a, and amber marks the arc through w.

For the default \(L=8\), the endpoint distance is one. The two arc diameters are at least \(8\) and \(\sqrt{65}\). The proof uses this type of lower bound for a sequence of increasingly distorted triples on one input curve. The four-vertex example demonstrates one triple.

Run `python3 render.py` in a Python environment with Pillow to generate the rotating GIF.
