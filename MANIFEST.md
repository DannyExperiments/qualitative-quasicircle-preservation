# Manifest

* `paper/` contains the manuscript, references and PDF build instructions.
* `proof/` contains the original Markdown proof.
* `visualization/` contains the rotating GIF, render source and offline guide.
* `verification/` and `scripts/` contain executable checks and their local replay.
* `audits/` contains literature and mathematical-review status reports.
* `release/` records pending release decisions.
* `SHA256SUMS.txt` lists checksums for the repository artifacts.
